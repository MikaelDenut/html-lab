# Font licences

Latin subsets in woff2 of free fonts, used as look-alike stand-ins for macOS system fonts. All files were subsetted (Basic Latin, Latin-1, Latin Extended-A, common punctuation), hinting removed, and some variable fonts were pinned to named instances; they are Modified Versions under the licences below.

Source snapshot: github.com/google/fonts at commit 86aced91de05cd4f96a06838124cca45be337b2b. The licence of each font was read from the file named in the Licence text column.

Fonts whose licence declares a Reserved Font Name were renamed inside the font and in the file name, as the SIL OFL requires for Modified Versions. For those, "Shipped as" differs from the original name.

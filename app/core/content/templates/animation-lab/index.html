How an animation works

@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

.ball:hover {
  animation: fade-in 1s;
}

@keyframes is the plan. It says how things look at the start (from) and at the end (to).

animation plays the plan. First the plan's name, then how long it takes.

Did you know? A film shows 24 still pictures every second. Your brain joins them into one moving picture.

Some people feel dizzy when things move. If their Mac asks for less motion, this lab stops every test. See the last block in style.css. Help: Less motion for some people

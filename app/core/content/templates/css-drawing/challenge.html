Draw your own face

This face is waiting for you. Open style.css and find the block called YOUR FACE. It has four lines marked LINE 1 to LINE 4. Change one, and look.

Pick a mood

These are the four lines to change in style.css:

.lab {
  --skin: #ffd27a;   /* LINE 1 */
  --eye: 2em;        /* LINE 2 */
  --mouth: 0deg;     /* LINE 3 */
  --cheeks: #ff8a6b; /* LINE 4 */
}

Things to try

  1. Make a frog: change LINE 1 to #7bd35b.
  2. Give it huge eyes: change LINE 2 to 3.5em.
  3. Turn the smile upside down: change LINE 3 to 180deg.
  4. Make the cheeks blue: change LINE 4 to #6ab0ff.
  5. Hard one: add <div class="face-eye middle"></div> on a new line just under the face-eye right line in this page's HTML. Not inside the div called face! The CSS for a third eye is already waiting.

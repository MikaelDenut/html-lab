How it works

Is this a real game, or just a website? It is both! There is no JavaScript here, only HTML and CSS. These are the tricks, with the important lines from style.css.

A label clicks its checkbox

Every coin is a checkbox. The box itself is hidden. What you see is its label, drawn to look like a coin. When you click a label, the browser clicks its checkbox for you. They belong together because for="coin-1" and id="coin-1" match.

<input class="coin-box" type="checkbox" id="coin-1">
<label class="coin" for="coin-1">
  <span class="hidden-text">Coin 1</span>
</label>

:checked changes the look

:checked means "this checkbox has a tick". The + means "the label right after it". So when a coin box gets a tick, its coin fades away, and the mouse can not click it again. In style.css the coin also does a little jump first.

.coin-box:checked + .coin {
  opacity: 0;
  pointer-events: none;
}

counter-increment counts

CSS can count! counter-reset starts a counter at 0. Every box with a tick adds 1. Then content writes the number on the screen.

.game { counter-reset: coins; }
.coin-box:checked { counter-increment: coins; }
.score::before {
  content: "Coins: " counter(coins) " of 8";
}

CSS counts from the top of the page to the bottom. That is why the score comes after all 8 coins in index.html.

:has() and :target ask questions

:has() looks inside a box. This rule asks: "Does the game have a coin box with no tick?" :not() turns the question around. When no coin is left, the Level clear banner shows.

.game:not(:has(.coin-box:not(:checked))) .level-clear {
  display: grid;
}

:target is the part of the page whose id is at the end of the address. The doors are links like href="#door-2". Click one, and the box with id="door-2" becomes the target, so it shows.

.result { display: none; }
.result:target { display: grid; }

Do real game sites work like this?

Not often. Most games on the web use JavaScript, a programming language that runs in the browser. It can move a hero with the arrow keys, play sounds and save your best score. This site has no JavaScript. It shows how far HTML and CSS can go on their own.

Try it yourself:

  • Move a coin: change left and top in .spot-1 in style.css.
  • Paint the coins: change --coin in :root.
  • Add a 9th coin: copy a coin in index.html and change its numbers to 9. Add a .spot-9 place in style.css, and change "of 8" to "of 9". Then change the 8 at the top of index.html and in the Level clear words.
